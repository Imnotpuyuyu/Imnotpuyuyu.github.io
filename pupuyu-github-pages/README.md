# 🥺 ぷゆゆ

GitHub Pages で公開できるブラウザミニゲームです。

## 遊び方
- 🥺をタップしてポイント獲得
- 動き始めた🥺が壁に当たるとポイント獲得
- 「タップ」「壁タッチ」を強化
- 「ショップ」から追加効果を購入
- 「共有」でゲーム画面をPNG保存

## GitHub Pages
1. このフォルダの中身をGitHubリポジトリのルートへアップロード
2. **Settings → Pages**
3. **Deploy from a branch**
4. `main` / `(root)` を指定して保存

## 効果音
```text
assets/
└── sfx/
    ├── tap.mp3
    └── wall.mp3
```

効果音ラボから素材をダウンロードし、上記ファイル名にして配置してください。
タップは「決定ボタンを押す3」などの柔らかい音、壁は「壁をドンと叩く」などの短い衝突音が合わせやすいです。

公式: https://soundeffect-lab.info/
